# Dino GIF Generator 🦖

A beginner-friendly Python project that converts multiple dinosaur image frames into a smooth animated GIF.

## Overview

This project creates an animated GIF using multiple PNG images.  
It uses the `imageio` library to read image frames and combine them into a looping GIF animation.

## Features

- Read image files using Python
- Store multiple images in a list
- Create a GIF from image frames
- Use external Python libraries
- Work with file paths in a Python project

## Technologies Used

- Python
- imageio
- OS module

## Files Included

```text
create_gif.py
dino1.png
dino2.png
dino3.png
dino4.png
dino.gif
```

## How to Run

Install the required library:

```bash
pip install imageio
```

Run the Python file:

```bash
python create_gif.py
```

The program creates an animated GIF file named:

```bash
dino.gif
```
